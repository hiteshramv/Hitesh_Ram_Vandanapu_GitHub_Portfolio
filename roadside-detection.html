Real-Time Roadside Object Detection

Retrained and deployed a YOLO11s object-detection model for real-time roadside perception using camera data collected from a real-world multi-sensor platform.

YOLO11s Python Object Detection Real-Time Perception

Overview

During my research internship at the Fraunhofer Institute for Transport and Infrastructure Systems (IVI), I worked on camera-based object detection for a roadside perception system.

The camera detector was based on YOLO11s. The model was retrained from a pretrained checkpoint using a custom dataset collected from the three RGB cameras of the roadside sensor platform.

The retrained detector was designed to distinguish vulnerable road users(Adults, Children, Cyclists) while also recognizing other traffic participants present in the scene.

The dataset was intentionally weighted toward vulnerable road users. Adult and child instances together account for 4,765 annotated instances.

Annotation: Images were labelled using LabelImg with axis-aligned bounding boxes. The dataset was collected from all three camera perspectives to capture different views of the roadside environment.

Why Retrain YOLO11s?

The pretrained detector did not provide the class separation required for the tracking application. In particular, generic person detections could not distinguish adults from children.

The tracking system also required a cyclist to be represented as a single object rather than treating the rider and bicycle as separate detections.

Target VRU classes
Adult Child Cyclist

Training

The model was trained for 120 epochs using yolo11s.pt as the initial pre trained weights, with a batch size of 16 and an input resolution of 640 × 640 pixels. A cosine learning rate schedule was applied with an initial rate of 0.01. Standard Ultralytics data augmentation was used, including random horizon tal flipping, HSV colour jitter, and mosaic augmentation.

Performance

96.7% mAP@0.5

The retrained YOLO11s model achieved 96.7% mAP@0.5 and 85.8% mAP@0.5:0.95 on the validation set. And was subsequently deployed as the camera-side detector for the roadside perception system.
