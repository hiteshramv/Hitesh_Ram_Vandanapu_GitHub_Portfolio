MASTER'S THESIS CASE STUDY

Files:
- thesis.html       Complete case-study page
- thesis.css        Styling for the case-study page
- assets/*.png      Figures cropped from the thesis report

INSTALLATION
1. Copy thesis.html and thesis.css into the same folder as your existing index.html.
2. Copy the assets folder into that same folder.
3. In index.html, change the first project card to include a link:

   <a class="project-link" href="thesis.html">View case study →</a>

4. The case-study page links back to index.html#projects.
